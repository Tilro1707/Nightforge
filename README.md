# Nightforge

A top-down survivors-like. Souls are both your score and your upgrade currency. Level up Fire, Water and Air, and combine them into combo spells: Steam (Fire + Water), Jet Lance (Water + Air) and Firestorm (Fire + Air). Each run lasts 5 minutes.

Made for [Mini Jam 219: Nocturne](https://itch.io/jam/mini-jam-219-nocturne).

## Tech

- Unity 6000.3.8f1

Open the folder in Unity Hub with the matching editor version.
